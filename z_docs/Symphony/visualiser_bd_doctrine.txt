Il y a plusieurs façons de visualiser l'état des tables dans Doctrine :

1.Via la console Symfony :

# Voir la structure des tables
php bin/console doctrine:schema:validate

# Voir le contenu d'une table spécifique
php bin/console doctrine:query:sql "SELECT * FROM user"

# Voir les migrations
php bin/console doctrine:migrations:status

Via le Symfony Profiler (en mode dev) :
Accédez à votre application avec ?debug=1
Cliquez sur la barre de debug en bas
Allez dans l'onglet "Doctrine"
Vous verrez toutes les requêtes et la structure

2. Via des commandes de debug :

# Voir toutes les entités
php bin/console debug:doctrine

# Voir une entité spécifique
php bin/console doctrine:mapping:info

# Voir le mapping détaillé d'une entité
php bin/console doctrine:mapping:describe App\\Entity\\User

3.Pour un affichage plus lisible des données :

# Installer le bundle pour un meilleur affichage
composer require doctrine/doctrine-fixtures-bundle --dev

# Puis utiliser
php bin/console debug:doctrine App\\Entity\\User

si je fais un changement dans la base des données doctrine ça va etre refleteé dans la bd xampp?

Oui, absolument ! Doctrine et XAMPP utilisent la même base de données MySQL. Voici comment ça fonctionne :
Configuration :

# Ce fichier pointe vers la base MySQL de XAMPP
DATABASE_URL="mysql://root:@127.0.0.1:3306/pharmacy?serverVersion=10.4.32-MariaDB&charset=utf8mb4"

Quand vous faites des changements :
Via Doctrine (migrations, commandes) → Visible dans phpMyAdmin
Via phpMyAdmin → Visible pour Doctrine
Les deux utilisent la même base MySQL
# Si vous faites un changement avec Doctrine
php bin/console doctrine:query:sql "UPDATE user SET roles = '[\"ROLE_ADMIN\"]' WHERE id = 1"

# Le changement sera visible dans :
# 1. phpMyAdmin (XAMPP)
# 2. Votre application Symfony

C'est la même base :
XAMPP fournit le serveur MySQL
phpMyAdmin est une interface pour gérer MySQL
Doctrine est un ORM qui communique avec MySQL
Tous travaillent sur les mêmes données
C'est pour ça qu'il faut faire attention aux changements manuels dans phpMyAdmin et les documenter dans les migrations Doctrine.
